# Coordinate-dependent local simplification

This isolated extension closes the fixed-retention limitation of the existing finite interval-output theorem. It constructs an actual finite gARG on the original finite node catalog when retained nodes vary between source breakpoint cells. The source-relevant instance retains all samples and every node with two distinct immediate children in the sample-extracted local relation. Its required constancy is proved from the original graph, not imposed on the caller.

## Exact theorem contract

`automatic_reencoded_local_simplification` takes a finite `GARG G`, a predicate `K : Coord -> Node -> Prop`, and proof that `K` is constant on each adjacent half-open cell generated by `G.breakpoints`. It returns an actual finite `GARG H` with:

- The same `Node` type and node identifiers, and `H.samples = G.samples`.
- Nonempty interval annotations and one canonical record per ordered parent-child pair.
- At every coordinate, exactly the relation `Contract (G.ExtractedAt x) (K x)`.
- Exactly the original strict ancestry from each retained starting node to each retained sample.
- The unique-local-parent property wherever the source has that property.
- Sample support whenever every sample is retained at every coordinate.
- `H.breakpoints` contained in `G.breakpoints`.

A `GARG` carries a proof of global topology acyclicity. This extension proves the required acyclicity for the union of the new coordinate relations by expanding each contracted edge to an original path. It does not assume that independently acyclic local relations automatically yield a globally acyclic graph.

The finite output reuses the existing cell-to-record construction after proving that both source edges and retained predicates can be transported across a cell. Outside all source cells, no contracted edge can exist, so no constancy premise is needed there.

## Samples and local branching

`KeepSamplesAndBranching G x a` means either that `a` is a designated sample or that two distinct nodes `b` and `c` are children of `a` in `G.ExtractedAt x`. This counts distinct immediate children, not records or interval fragments. It is evaluated before contraction.

`samples_and_branching_cellwise` derives this predicate's cell constancy from the already proved constancy of the sample-extracted local relation. `samples_and_branching_representable` therefore requires only `G`; it supplies all the output guarantees above with unconditional sample support. It also proves that an unretained identifier has no incident output edges at that coordinate. `suppressed_at_most_one_child` proves that a suppressed source node has at most one extracted local child.

This instance genuinely permits the same node to be retained in one genomic cell and suppressed in another. Keeping the original catalog does not mean that the node remains an active local vertex everywhere.

## Source relationship and limits

The modeled operation corresponds to retaining samples and local branching structure while bypassing unwanted local vertices, as discussed around Appendix G of Wong et al. (2024), DOI [10.1093/genetics/iyae100](https://doi.org/10.1093/genetics/iyae100). Appendix G begins on journal page 16, physical page 17 of the [Edinburgh publisher-version PDF](https://www.pure.ed.ac.uk/ws/portalfiles/portal/458588307/iyae100.pdf#page=17). The adjacent source intake preserves authoritative article XML and extraction provenance.

The existing `ExtractedAt` operation restricts edges to those leading toward designated samples. That support restriction is not claimed to be the whole operation depicted in Fig. 3, including truncation above local MRCAs. This module composes that explicitly defined restriction with local contraction. It does not claim an equivalence to all tskit simplification options or prove a global minimality characterization of the output.

The construction is noncomputable Lean mathematics, not an executable simplifier or certified canonical serialization. Canonical records mean one row per endpoint pair; adjacent interval fragments are not merged. Old redundant breakpoints may remain even though no new breakpoints are introduced. Unused identifiers remain in the original catalog, and physical node compaction is a separate task. Preserved ancestry is at one fixed coordinate; event identities, path lengths and removed crossover information are not preserved by the theorem. No biological species result, empirical validity claim or novelty claim is made.
