# Wong et al. (2024): source-faithful formalization

The current deterministic result constructs canonical finite interval output
after local-MRCA truncation and sample/branching contraction. Start with the
[worked example and exact scope](CURRENT.md), then use the
[complete source-claim table](COVERAGE.md) and
[machine-readable ledger](coverage.json).

This edition preserves the public 209-endpoint baseline and stages 65 further
selected endpoints in three modules. The proposed real-development audit has
274 endpoints, including other research already present in that library.
Local module passes, combined verification, independent statement review and
hosted CI are separate evidence states. The current release evidence must be
consulted before treating this stage as publicly verified.

The ledger covers the main text and Appendices A–I at claim-family level.
An inventory is not a proof of every claim: stochastic processes, expected
costs, executable export and external software/empirical claims remain
explicitly open. No whole-paper completion or new biological theorem is
claimed.

The source is Yan Wong et al., *A general and efficient representation of
ancestral recombination graphs*, GENETICS 228(1), iyae100 (2024),
[DOI 10.1093/genetics/iyae100](https://doi.org/10.1093/genetics/iyae100).
Source locators, the primary XML hash and prior integration evidence remain
in the ledger. The [209-endpoint coverage table](history/COVERAGE-public-209.md)
is retained as history.

The public repository's root README and programme progress pages are owned
by the programme auditor. This packet changes only the Wong completion
pages, the three modules, their library registrations and the endpoint audit.
