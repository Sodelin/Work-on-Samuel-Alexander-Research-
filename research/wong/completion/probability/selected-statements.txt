## WongBigARGDrift.weighted_gap

```lean
lemma weighted_gap (θ : ℝ) (hθ : 0 ≤ θ) (N : ℕ) (hN : θ ≤ N)
    (j : ℕ) (hj : 1 ≤ j) :
    θ + j ≤ base N * ((j : ℝ) * weight N j - θ * weight N (j + 1))
```

## WongBigARGDrift.potential_drift

```lean
theorem potential_drift (θ : ℝ) (hθ : 0 ≤ θ) (N : ℕ) (hN : θ ≤ N)
    (j : ℕ) (hj : 1 ≤ j) :
    (θ / (θ + j)) * potential N (j + 1) +
      ((j : ℝ) / (θ + j)) * potential N (j - 1) + 1 ≤ potential N j
```
