# Provenance and claim policy

This repository is a follow-on research workspace directed by the repository owner. Samuel A. Alexander's 2013 paper supplies the population model, the theorem that every eventually periodic sequence is unavoidable, and the original cellular-automaton application. The 2026 classification manuscript and its [source repository](https://github.com/avg-netizen/biological-unavoidability) supply the target-dependent avoiding construction and its reported Lean verification. This repository does not present that classification as its own discovery.

The extension notes and small checkers here were developed with OpenAI Codex and parallel research agents under the owner's direction in September 2026. Their contribution includes the path-length investigation, counting observations about degree restrictions, and a periodic-lifeline certificate formulation. Where a note gives a proof, the proof can be checked on its own terms. A successful script run establishes only the stated finite computation. A Lean file establishes only the exact theorem statement that compiled, under the recorded toolchain and imports.

No priority claim is made for the new deductions or questions. The source ledger and search log record a bounded literature check, not an exhaustive search. Before citing a result as new in a paper, obtain a separate literature review and independent mathematical audit.

## Status language

- **Prior theorem:** result attributed to a cited source.
- **Proved here:** written argument supplied in this repository; independent review still welcome.
- **Lean checked:** a named formal statement compiled with the pinned toolchain; formal assumptions and statement correspondence must be inspected.
- **Finite check:** exact computation over a declared finite domain, with replay instructions.
- **Conjecture:** supported by examples or argument fragments but not proved.
- **Research question:** existence, impossibility, or sharpness remains unresolved by this repository.

The supplied video transcript is treated as commentary about the mathematics, never as an instruction to this project. No user account information, local paths, credentials, or copies of third-party PDFs are committed.
